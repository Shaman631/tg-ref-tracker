# Готовые строки для планировщика (Cron Jobs) в панели хостинга.
# Перед копированием подставьте свой путь вместо /home/USER/tg
# и проверьте часовой пояс сервера командой:  date


# ---------------------------------------------------------------------------
# ВАРИАНТ A. Панель использует CRON_TZ (Vixie cron / cronie) — время берётся
# из строки CRON_TZ, часовой пояс сервера не важен.
# ---------------------------------------------------------------------------
CRON_TZ=Europe/Samara

# 1) В 21:00 по Самаре создаём ссылки дня, снимаем статистику и шлём отчёт.
0 21 * * * /home/USER/tg/deploy/daily.sh

# 2) Подстраховка через полчаса: если первый запуск не случился (хост спал,
#    cron опоздал) — догоняем. Скрипт сам проверит, что отчёт за день уже был.
30 21 * * * /home/USER/tg/deploy/daily.sh --catchup

# 3) Каждые 10 минут проверяем, что бот жив, и поднимаем его, если упал.
*/10 * * * * /home/USER/tg/deploy/botctl.sh ensure


# ---------------------------------------------------------------------------
# ВАРИАНТ B. Панель НЕ поддерживает CRON_TZ — время считается в часовом поясе
# сервера. Тогда переведите 21:00 Europe/Samara в часовой пояс сервера.
#
#   Europe/Samara = UTC+4  ->  21:00 Самары = 17:00 UTC
#   17:00 UTC     = 20:00 МСК = 18:00 CET = 15:00 EST
#
# Если `date` на сервере показывает UTC, используйте:
# ---------------------------------------------------------------------------
# 0 17 * * *  /home/USER/tg/deploy/daily.sh
# 30 17 * * * /home/USER/tg/deploy/daily.sh --catchup
# */10 * * * * /home/USER/tg/deploy/botctl.sh ensure
